CSV を読み込むか、数値をそのまま貼り付けるだけで、**記述統計から仮説検定・分散分析・回帰・決定木・時系列・ディープラーニングまで**を実行できる静的サイトです。サーバーもインストールも不要で、GitHub Pages にファイルを置くだけで動きます。

## 特徴

### 1. インストール不要・完全クライアントサイド

Python も R も要りません。ブラウザで URL を開くだけです。社内のデータを扱うとき、外部サービスにアップロードすることへの抵抗がある場面でも使えます。

### 2. 結果に「読み方」が必ず付く

どの分析にも解説パネルがあり、**p 値・効果量・信頼区間・前提条件の充足状況**を日本語で説明します。「有意でした」で終わらせず、「その数字をどう読むべきか」「どこが危ういか」まで書きます。

### 3. やりたいことから手法にたどり着ける

統計の用語を知らなくても、「やりたいことから探す」の質問に答えていくと、**使う手法・開く画面・見るべき数値・落とし穴**まで案内されます。診断のゴールは 32 通りあります。

### 4. 統計ハンドブックを内蔵

確率分布・検定の選び方・回帰モデル・回帰診断・機械学習・時系列・用語集（90 語）を、図と表つきで収録しています。統計検定 3〜2 級の学習にもそのまま使えます。

### 5. 外部の統計ライブラリに依存しない

確率分布と検定は、不完全ガンマ関数・不完全ベータ関数といった特殊関数から自前で実装しています。使っている外部ライブラリは、作図（Plotly.js）・CSV パース（PapaParse）・ニューラルネット（TensorFlow.js）の 3 つだけです。

## データの準備

### CSV ファイルから読み込む

- **1 行目を列名**として扱います
- 文字コードは **UTF-8 と Shift_JIS を自動判別**します（Excel から書き出した CSV もそのまま読めます）
- 区切り文字はカンマ・タブを自動判定します
- 空欄は欠測として扱い、プレビューで `·` と表示されます

推奨する形（横持ち・1 行 1 観測）:

```csv
群,年齢,BMI,収縮期血圧,再発
投与,58,24.1,126,1
対照,61,26.3,138,0
投与,45,22.8,119,0
```

### 直接入力する

カンマ・タブ・空白・改行のいずれでも区切れます。列名は省略できます。

```
52.3, 48.9, 61.2
55.1, 49.4, 58.7
```

1 列だけ貼れば 1 変数として扱います。t 検定や記述統計だけを試したいときはこれで十分です。

### 列の型判定

各列は自動で **数値 / カテゴリ** に判定されます。判定結果は「列の型と欠測」の表で確認できます。数値なのにカテゴリと判定された場合は、桁区切りのカンマや単位（`1,200円` など）が混じっていないか確認してください。

### 対応のあるデータ（反復測定・Friedman）の形

同じ対象を複数条件で測ったデータは、**条件を列に並べた横持ち**にしてください。

```csv
前,中,後
52.1,55.4,58.9
48.3,50.2,54.1
```

### 欠測値の扱い

分析に使う列のいずれかが欠測している行は、**丸ごと除外**されます（リストワイズ除去）。欠測が多いデータでは有効な行数が大きく減るため、実行後に表示される `n` を必ず確認してください。

## 画面ごとの使い方

### 記述統計とプロット

12 種類のプロットを切り替えられます。

| プロット | 用途 |
|---|---|
| ヒストグラム＋KDE | 分布の形、山の数、偏りを見る |
| バイオリン | 群ごとの分布の形を比較する |
| 箱ひげ | 中央値・四分位・外れ値を見る |
| ストリップ | 個々の観測値をすべて見る（n が少ないとき有効） |
| リッジライン | 多群の分布を重ねて比較する |
| 経験累積分布（ECDF） | 「◯◯以下が何 %か」を読む |
| Q-Q プロット | 正規性を目視で確認する |
| 散布図＋回帰 | 2 変数の関係と 95% 信頼帯 |
| 2 次元密度 | 点が重なりすぎるときの分布の濃淡 |
| 散布図行列 | 数値変数どうしの関係を一覧する |
| 平均＋誤差棒 | 群ごとの平均と 95% 信頼区間 |
| 平行座標 | 多変量のパターンを俯瞰する |

同時に、Shapiro–Wilk・Jarque–Bera・Anderson–Darling・Kolmogorov–Smirnov の 4 つの正規性検定が実行されます。

### 確率分布ラボ

14 種類の分布について、母数を変えながら密度関数・累積分布関数・確率・パーセント点を確認できます。読み込んだデータのヒストグラムを重ねたり、**最尤法で当てはめ**たりもできます（正規・対数正規・指数・ポアソン・ガンマ・一様に対応）。

### 平均の検定（t / z）

1 標本 t 検定、2 標本 t 検定（Welch / Student）、対応のある t 検定、z 検定（母分散既知）に対応します。検定統計量と棄却域の図が同時に描かれるので、「どれくらいギリギリだったのか」が視覚的に分かります。

前提条件パネルには、正規性・等分散性・**検出力の目安**が表示されます。

### 分散分析・群間比較

| 手法 | データの形 |
|---|---|
| 一元配置分散分析 ＋ 多重比較（Holm / Bonferroni） | 数値列 ＋ 群を表すカテゴリ列 |
| 二元配置分散分析（交互作用つき） | 数値列 ＋ カテゴリ列 2 つ |
| 反復測定分散分析（Greenhouse–Geisser 補正つき） | 条件ごとの列を横持ち |
| Friedman 検定 | 条件ごとの列を横持ち |
| Kruskal–Wallis 検定 | 数値列 ＋ 群を表すカテゴリ列 |
| Mann–Whitney U 検定 | 同上（2 群のみ） |
| Wilcoxon 符号付き順位検定 | 同上（対応のある 2 条件） |

Levene 検定と Bartlett 検定による等分散性の確認も自動で行われます。

### 母比率・母分散

数を直接入力して比率の検定ができます。正規近似の p 値と**正確二項検定**の p 値の両方が出るので、標本が小さいときも安心です。信頼区間は Wald 区間ではなく **Wilson 区間**を主に表示します。

### カテゴリデータ（χ²）

独立性の検定、適合度検定、度数の直接入力、McNemar 検定に対応します。2×2 表では **Fisher の正確確率検定**と Yates 補正が自動で併記されます。調整済み標準化残差のヒートマップで、どのセルが効いているかも分かります。

### 相関・主成分

Pearson / Spearman / Kendall の相関行列、偏相関、散布図行列、主成分分析（スクリープロット・バイプロット）が実行できます。

### 回帰分析

- **線形回帰**：重回帰、多項式回帰、標準化係数 β、VIF、Durbin–Watson、Cook 距離、てこ比、信頼区間と予測区間、AIC / BIC
- **ポアソン回帰**：件数データ向け。発生率比（IRR）と**過分散の診断**つき

診断図が 4 枚（残差 vs 予測値／Q-Q／てこ比 vs 残差／当てはめ）同時に表示されます。

### ロジスティック回帰

IRLS による最尤推定、オッズ比と信頼区間、ROC 曲線と AUC、混同行列。**判定閾値をスライダーで動かせる**ので、「見逃しを減らすか、誤検知を減らすか」のトレードオフをその場で確認できます。完全分離が起きた場合は警告し、L2 正則化で対処できます。

### 決定木・森

CART による分類木・回帰木を作り、**木の構造を図として表示**します。ランダムフォレスト（OOB 評価）、決定境界の可視化、並べ替え重要度、部分依存プロット（PDP）にも対応します。

### 時系列解析

ADF 検定、ACF / PACF、古典的季節分解（加法・乗法）、Holt–Winters 指数平滑、AR モデル、加法モデル（区分線形トレンド＋フーリエ季節項）、Ljung–Box 検定。

### 株価分析

終値の列を指定すると、リターン・年率ボラティリティ・シャープ・ソルティノ・カルマー・最大ドローダウン・VaR・CVaR、移動平均・ボリンジャーバンド・RSI・MACD をまとめて計算します。

### 多層パーセプトロン

TensorFlow.js による MLP。回帰・2 値分類・多クラス分類に対応し、隠れ層構成・活性化関数・最適化アルゴリズム・学習率・ドロップアウト・L2 正則化を指定できます。学習曲線がリアルタイムで描画され、**過学習が始まった時点**を解説パネルが指摘します。

| 知りたいこと | データの形 | 手法 |
|---|---|---|
| 母平均がある値と違うか | 数値 1 群 | 1 標本 t 検定 |
| 2 群の平均が違うか | 数値 2 群・対応なし | Welch の t 検定 |
| 前後で変化したか | 数値 2 条件・対応あり | 対応のある t 検定 |
| 3 群以上の平均が違うか | 数値 ＋ カテゴリ | 一元配置分散分析 ＋ 多重比較 |
| 3 条件以上を同じ人で比べる | 条件ごとの列（横持ち） | 反復測定分散分析 |
| 正規性が崩れている | 状況により | Mann–Whitney / Kruskal–Wallis / Wilcoxon / Friedman |
| 2 要因の効果と交互作用 | 数値 ＋ カテゴリ 2 つ | 二元配置分散分析 |
| 比率が想定と違うか | 成功数と試行数 | 母比率の検定 / 正確二項検定 |
| 前後で ○× が変わったか | 対応のある 2 値 | McNemar 検定 |
| カテゴリ間に関連があるか | クロス集計 | χ² 独立性検定 / Fisher |
| ばらつきが基準と違うか | 数値 1〜2 群 | χ² 検定 / F 検定 |
| 2 変数が一緒に動くか | 数値 2 変数 | 相関分析 |
| 数値を予測・要因を測る | 数値 y ＋ 説明変数 | 重回帰分析 |
| 件数を予測する | 非負整数 y ＋ 説明変数 | ポアソン回帰 |
| 起こる／起こらないを予測 | 2 値 y ＋ 説明変数 | ロジスティック回帰 |
| 解釈しやすいルールが欲しい | y ＋ 説明変数 | 決定木・ランダムフォレスト |
| 将来の値を予測したい | 時系列 | 指数平滑 / AR / 加法モデル |
| 複雑な非線形関係を捉えたい | 数値多変量 | 多層パーセプトロン |

## 結果の読み方の基本

### p 値だけを見ない

p 値は「帰無仮説が正しいと仮定したとき、観測されたデータ以上に極端な結果が出る確率」です。次のものでは**ありません**。

- 帰無仮説が正しい確率
- 効果の大きさ
- 結果の重要性

標本を増やせば、どんなに小さな差でも有意になります。逆に、有意でないことは「差がないこと」の証明にはなりません。

### 必ずセットで見る 3 点

1. **p 値** — 偶然で説明できるか
2. **効果量** — 差がどれくらい大きいか（Cohen の d、η²、Cramér の V、オッズ比など）
3. **信頼区間** — 推定がどれくらい精確か（**区間の幅**が情報）

### 前提条件を確認する

正規性・等分散性・独立性が崩れていれば、p 値そのものが信用できません。本ツールは前提条件のチェック結果を自動表示します。

## 注意点と限界

### 近似を用いている箇所

| 項目 | 実装 |
|---|---|
| Shapiro–Wilk の p 値 | Royston (1992/1995) の近似式 |
| Mann–Whitney / Wilcoxon | 正規近似（同順位補正・連続性補正あり） |
| Kolmogorov–Smirnov の p 値 | Lilliefors 近似 |
| ADF 検定 | 大標本の臨界値（MacKinnon）との比較。p 値は算出しない |
| Holt–Winters の予測区間 | 残差の標準偏差に基づく簡易式 |
| 多重比較 | Holm / Bonferroni（Tukey の HSD は未実装） |

極端に小さい標本では、R や SAS の正確法と数値が一致しないことがあります。

### 実装していない主な手法

- Tukey の HSD、Dunnett 検定、Games–Howell 検定、Cochran の Q 検定
- 負の二項回帰、多項ロジット回帰、順序ロジット回帰、ベータ回帰
- 生存時間解析（Kaplan–Meier、Cox 比例ハザードモデル）
- 混合効果モデル、一般化推定方程式（GEE）
- ARIMA の MA 項、SARIMA、GARCH
- ベイズ推定（MCMC、事後分布）
- クラスタリング、SVM、勾配ブースティング
- SHAP 値、因果推論（傾向スコア、操作変数法、差分の差分法）

### 「Prophet」ではありません

時系列と株価の加法モデルは、Prophet の考え方（区分線形トレンド＋変化点＋フーリエ季節項）を参考に**自前で実装したもの**です。Meta の Prophet そのものではなく、MCMC による事後分布の推定も休日効果も含んでいません。予測区間は残差の標準偏差に基づく簡易的なものです。

### カテゴリ変数を説明変数に使うとき

回帰系の画面は数値列のみを受け取ります。カテゴリを説明変数にしたい場合は、CSV 側で 0/1 のダミー列を作ってから読み込んでください（k 水準なら k−1 列）。

### データ量の目安

すべての計算がブラウザ上で動くため、極端に大きなデータでは重くなります。数千行 × 数十列までを想定しています。相関行列・散布図行列・ランダムフォレスト・MLP は、行数が増えると時間がかかります。

## 実装と検証について

確率分布・検定・回帰は外部ライブラリに依存せず、次のように実装・検証しています。

**実装**

- Lanczos 近似による対数ガンマ関数
- 級数展開と連分数による正則化不完全ガンマ関数 P(a, x)
- 連分数による正則化不完全ベータ関数 I_x(a, b)
- これらを土台に、正規・t・カイ二乗・F・二項・ポアソンほかの分布関数を構成
- 逆関数は Acklam の有理近似（正規）と二分法（その他）

**検証**

- 分布関数の値を数値積分（Simpson 法）と突き合わせ
- t 分布・カイ二乗分布・F 分布のパーセント点を統計数値表と照合
- 分散分析の平方和分解を手計算と照合（SSB + SSW = SST を厳密に確認）
- 回帰係数を正規方程式の手計算と照合、予測区間を理論式と照合
- ポアソン回帰は既知の母数から生成したデータでの復元と、スコア方程式 X'(y − μ) = 0 の成立を確認
- 反復測定分散分析は平方和分解の恒等式と、複合対称データで Greenhouse–Geisser の ε が 1 になることを確認
- McNemar 検定は文献の数値例と一致することを確認
- MLP は回帰・2 値分類・多クラス分類の 3 パターンで学習が収束することを確認
